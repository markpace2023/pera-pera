# SpendFlow Android APK

The SpendFlow debug APK has been built with multi-currency support and placed in the project root directory:

- **Filename**: `SpendFlow-debug.apk`
- **Path**: `/SpendFlow-debug.apk` (located in root directory)
- **Size**: ~25 MB
- **Latest Features Included**:
  - **Account Currency Selection**: Choose any world currency (PHP, USD, EUR, GBP, JPY, CAD, AUD, SGD, etc.) when creating or editing accounts. Defaults to primary currency.
  - **Primary Currency Settings**: Dedicated Primary Currency dropdown with live exchange rates status, cached offline fallback, and internet refresh.
  - **Dashboard Total Net Worth**: Collapsed view displays converted net worth in primary currency via live exchange rates with multi-currency indicator badge.
  - **Opened Currency Breakdown**: Tap "View Breakdown by Currency" on the Net Worth card to see separated asset and debt totals partitioned per currency along with live exchange rates.
  - **Multi-Currency Transactions**: Non-primary currency transactions automatically show their converted equivalent in the ledger and a detailed conversion card when viewed.

### Download Options:
1. **From the File Explorer**:
   In the file browser on the left, locate `SpendFlow-debug.apk` in the root folder, right-click (or click the three dots `⋮`), and choose **Download**.
2. **From AI Studio App Settings**:
   Click the three dots (`⋮`) or the **Settings** menu at the top-right of AI Studio, then select **Export** / **Download APK/AAB**.
