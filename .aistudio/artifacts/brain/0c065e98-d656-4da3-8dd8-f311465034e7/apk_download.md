# SpendFlow Android APK

The SpendFlow debug APK has been built and placed in the project root directory:

- **Filename**: `SpendFlow-debug.apk`
- **Path**: `/SpendFlow-debug.apk` (located in root directory)
- **Size**: ~25 MB
- **Latest Features Included**:
  - **Dynamic Keyword Learning (Grows With Usage)**: Every transaction you save automatically expands the vocabulary for that category. Specific store names, brands, and item descriptions (e.g., `"7-Eleven"`, `"Decathlon"`, `"Aling Nena"`) automatically become permanent keywords for that category in all future entries.
  - **Transaction History Category Matching**: When note or title is present, SpendFlow automatically checks your recent transaction history. If an identical past transaction exists, its category is automatically reused.
  - **Category Keyword Matching**: Each category has an extensive built-in keyword dictionary combined with your dynamically learned keywords.
  - **Multi-Category Selection Prompt**: When multiple categories match the transaction note/title (e.g. text containing words for multiple categories), a dialog pops up with the matched categories so you can quickly tap and choose the correct one.
  - **Most Recently Used (MRU) Account & Category Ordering**: Picked accounts and categories adaptively move to the 1st position in recency order across widgets and sheets.
  - **Account Currency Selection & Live Multi-Currency Support**: Full world currency support (PHP, USD, EUR, GBP, JPY, CAD, AUD, SGD, etc.) with real-time conversion and currency breakdown.
  - **Expanded Category Icons**: Icons for Family, Grants, Home, Motorcycle, Telephone, Tools, and Other Expenses.

### Download Options:
1. **From the File Explorer**:
   In the file browser on the left, locate `SpendFlow-debug.apk` in the root folder, right-click (or click the three dots `⋮`), and choose **Download**.
2. **From AI Studio App Settings**:
   Click the three dots (`⋮`) or the **Settings** menu at the top-right of AI Studio, then select **Export** / **Download APK/AAB**.
